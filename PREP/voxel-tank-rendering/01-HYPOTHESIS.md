# Prior: voxel-tank rendering studies

RCCM is the physics of this project. The adversarial target is the rendering and teaching design.

Before reading the idea or full formal source, I expect that a small set of coordinated views will teach the tensor better than a single all-purpose voxel rendering: a volume for field location, a local probe for directional structure, and an operation view for how neighbouring states produce change. I expect colour alone to hide sign, handedness, and the difference between a field value and its gradient.

Disproof conditions: the idea requires a different interaction substrate; the source cannot support these visual mappings; two views duplicate the same learning work; or a learner cannot predict which mark changes when one source variable changes.

Planned control: hold the physical state fixed when switching representation. Change one physical input at a time within each study. Record the actual encoded quantity, source equation, and prediction prompt.
