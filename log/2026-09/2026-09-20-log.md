# 2026-09-20 — First Bend foothold

## Goal and scope

- User's stated destination: implement tau fluidics in Bend for games and
  simulations, while personally mastering the science.
- User requested the simplest directionally useful start in `./bend/`, not
  a from-scratch implementation of everything.
- Selected one frozen fluid sample: normalized speed maps to dynamic pressure
  fraction and residual static pressure fraction (`alpha_s_sq`).
- Deferred meshes, time integration, tensors, engine adapters and GPU work.
  Reused Bend `Base` rather than adding numeric infrastructure.

## Sources and boundary

- Read the focused TeX's section 2 ledger and the condensed TeX's
  `eq:admittance_pressure_ratio` derivation.
- Explicit restriction: zero macroscopic and shear loads, one translational
  speed. The implementation follows the squared admittance equation; the
  condensed glossary's ratio wording is not silently substituted.
- No claim of scientific validation or universal formal proof.

## Evidence and verification

- Bend 2.0.21 exists at `~/.bend/bin/bend`, outside this session's `PATH`.
- Both entry points type-check; emitted JavaScript runs under Node 24.1.0.
- The half-speed demo gives `0.25` used, `0.75` remaining. Ten regression
  cases pass, including rejection of negative, excessive and nonfinite input.
- A deliberately broken split in an in-memory copy of the emitted JavaScript
  is rejected with exit 1. Unmodified sources also build/run from `bend/`.
- `F32` primitives do not evaluate in the proof checker here. Tests therefore
  execute on the target and return a nonzero exit on failure.
- Native validation is blocked by the Apple compiler's unaccepted Xcode
  licence; no licence or system configuration was changed.
