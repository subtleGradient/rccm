# 2026-09-21 — Formalization assessment and proposal

Tom requested an assessment of the current Bend asymmetric-tensor work and
a proposal toward formally specified RCCM simulations, toys, experiments and
eventually quantum chemistry. RCCM is the working physical hypothesis; the
purpose of formalization is to expose consequences and possible failures
while letting code and interaction carry learning before advanced mathematics
is personally mastered. This is a proposal request, not implementation of the
full research program.

The assessment is in
[the formalization proposal](../../docs/asymmetric-tensor-formalization-proposal.md).
Read-only parallel audits covered proof scope, TeX/source obligations and
the installed Bend toolchain. Existing F1–F11 source findings remain open;
they were not newly discovered or resolved by this assessment.

`verify-course.py --mutations`: 180 declarations, twenty demos and intended
failures, 1,035 independent exact API readings on CPU threads 1 and 2,

Assessment: a substantial exact reference kernel and field-learning lab;
no closed coupled RCCM dynamics. Most useful route: source/convention
manifest, stronger reusable algebra/calculus semantics, then a restricted
first-order transverse-wave sector with constraints, energy balance and
numerical evidence. Native F32 is axiomatic in the inspected Bend toolchain;
compiled Nat has a finite runtime bound; proof status must not be transferred
silently to compiled execution or physical validation.

No new learner mastery was observed. Durable preference clarified: build
understanding through runnable formal models and experiments; avoid requiring
completion of a mathematics syllabus before useful interaction.

The completed proposal recommends six small implementation checkpoints toward
an exact signed wave contract and then a numerical pulse toy. It separates
the claim/source manifest, exact mathematics, discretization, numeric backend
and experimental observables. Later stages add sources and spin/energy
exchange, capacity feedback, empirical validation and explicit quantum-state
projection before chemistry. A supplied effective quantum benchmark branch
is an optional earlier learning path; it is not a derived RCCM result.

The wave candidate follows the printed matrix's signs, with normalized flux
`-c e cross b`; the disagreement with the printed first-order pair requires
a recorded model/convention decision. Its fixed-background linearization
must not be treated as finite-amplitude full-ledger evolution. No canonical
TeX, existing law, implementation or submodule was modified. The root atlas
and course index link the proposal. No further build was started.
