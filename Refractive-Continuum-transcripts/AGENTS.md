# Transcript collection guidance

This folder contains a curated reading map at [`README.md`](README.md).

Read `README.md` before:

- choosing which transcript(s) are relevant to a topic or question;
- summarizing, comparing, or analyzing the channel as a whole;
- tracing dependencies or relationships among the channel’s arguments;
- recommending a reading order or onboarding someone to the collection; or
- adding, removing, renaming, or reorganizing transcript files.

For a question about one explicitly named video, you may open that `.txt` file
directly. Consult `README.md` as well when the answer depends on surrounding
concepts, later revisions, or related transcripts.

The README is a navigation aid, not a substitute for the source material.
Before quoting, attributing, or evaluating a claim, read the relevant `.txt`
transcript. If a technical term, symbol, or proper name appears mistranscribed,
check the corresponding `.vtt` caption source. Use `manifest.csv` for video
URLs, dates, durations, source filenames, and word counts.

When the transcript collection changes, update `README.md` so every `.txt`
transcript remains linked and has a specific reason to read it.
