# Refractive Continuum transcript reading map

This folder contains 65 text transcripts: all 51 publicly listed videos on the
[Refractive Continuum YouTube channel](https://www.youtube.com/@Refractive.Continuum)
and 14 selected videos from
[Binyamin Tsadik](https://www.youtube.com/@Binyamin.Tsadik).
The inventory was checked on 2026-09-09; the original 42 transcripts were
captured on 2026-07-29 and retained, and 23 transcripts were added in this update.

The requested phrase “Binyamin Tsadik and Refractive Continuum” is the
collaboration byline on the Standard Model video, not an additional video title.
The exact selection and source URLs are recorded in
[`source-inventory.json`](source-inventory.json).
Sections 1–7 preserve the original reading map; sections 8–9 index the additions.

The channel develops one evolving, speculative continuum-mechanics account of
physics. No clean taxonomy can make its subjects independent: gravity,
particles, light, material phase, measurement, and cosmology repeatedly fold
back into the same proposed “tau fluid.” The organization below is therefore a
dependency-aware reading path—the least unfit arrangement—not a claim that the
sections are genuinely separate.

Each note explains what question the transcript is useful for investigating,
not whether its scientific claims are established. The transcripts come from
YouTube captions, so check the retained `.vtt` source when a symbol, name, or
technical term looks suspicious. See [`manifest.csv`](manifest.csv) for dates,
durations, URLs, caption sources, and word counts.

## Import and verification

The 2026-09-09 import used yt-dlp 2026.08.19 through Nix, with nixpkgs pinned to
`a391f95d4557d685fd8e5dc0d4b1f9271aa2f342`. The older default `nixpkgs#yt-dlp`
resolved to 2025.06.09 and could not enumerate the current YouTube video layout.
The channel root was enumerated for Refractive Continuum; videos, streams,
and Shorts were checked on Binyamin Tsadik to resolve the requested selection.
Only the selected Binyamin videos were downloaded.

English original auto-captions (`en-orig`) are preferred. Existing `.en.vtt`
files are retained. Some duplicate `en` downloads returned HTTP 429; original
English captions cover every selected video. When the packaged curl backend
reported DNS failures, the affected caption URLs extracted into `.info.json`
were fetched with Nix Python's standard HTTP client. No audio or video was
downloaded, and no substitute speech recognition was used.

The raw `.vtt` and `.info.json` files are retained locally and remain ignored
by Git under the existing repository rules. Text transcripts, the CSV
manifest, and the source inventory are versioned. Captions can contain errors;
the conversion strips timing/markup, merges rolling-cue overlap, and groups
sentences without rewriting their wording.

To fetch the recorded selection again, run from the repository root:

```sh
python3 -c 'import json; print("\n".join(v["url"] for v in json.load(open("Refractive-Continuum-transcripts/source-inventory.json"))["videos"]))' > /tmp/rccm-transcript-urls.txt
nix shell github:NixOS/nixpkgs/a391f95d4557d685fd8e5dc0d4b1f9271aa2f342#yt-dlp --command yt-dlp \
  --skip-download --write-subs --write-auto-subs --sub-langs en-orig \
  --sub-format vtt --write-info-json --no-overwrites --sleep-subtitles 3 \
  -o 'Refractive-Continuum-transcripts/%(upload_date)s - %(title)s [%(id)s].%(ext)s' \
  --batch-file /tmp/rccm-transcript-urls.txt
nix shell nixpkgs#python3 --command python3 Refractive-Continuum-transcripts/_convert_vtt.py
```

This replays the recorded selection; discovering later uploads requires a new
channel inventory. The converter audits exact video-ID coverage against
`source-inventory.json`, rejects duplicate IDs and empty transcripts, and checks
for unstripped VTT markup. All 65 selected IDs passed after this import.
